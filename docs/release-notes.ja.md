# リリースノート — 0.6.1

[トップ](../README.ja.md)

保守リリースです。シーン・操作・音楽・測定結果は 0.6.0 から変わりません。変更したのはデモ ROM の宣言方法と、将来の誤りを防ぐ仕組みです。

テクニカルデモの ROM を、ASCII16-X ではなく標準の **ASCII16** として宣言するようにしました。バンク切り替えのコードは元から両方のマッパーが受け付ける形式で書き込んでいたため、ROM の挙動は同一で、ASCII16-X 対応ハードでもそのまま動作します。ASCII16 を選んだのは、対応環境が圧倒的に広く、このデモが拡張機能を必要としないためです。ただし現時点では将来のための余地という位置づけです。V9968 は実機としては少数の FPGA カートリッジしか存在せず、現実的な実行環境はエミュレーターだからです。

デモの起動スクリプトは、既定で ZIP 同梱の ROM を使うようになりました。従来はローカルの `build/` 出力が優先されたため、一度ビルドした開発者が更新後も古い ROM を使い続けても気づけませんでした。開発者は `-UseBuild` で自分のビルドを選択します。

フレーム数をバンク配置情報とともに生成し、実行時のマスクに使うようにしました。生成するフレーム数を変更しても、次の資産を読み込むことはありません。また ASCII16 の 256 バンク上限を超える ROM は生成時に停止し、エラーメッセージが ASCII16-X への切り替えを案内します。

Releases の Assets から 0.6.1 の ZIP 全体を新しいフォルダへ展開し、対応する setup BAT を実行してください。既存の 0.5.0・0.6.0 環境はそのまま使えます。上書きセットアップはできず、停止します。

BIOS・エミュレーター実行ファイルは同梱しません。[デモの制限](../demos/v9968-tech-demo/README.ja.md)と[ベンチマークの測定条件](../demos/scene3-benchmark/README.ja.md)も参照してください。
