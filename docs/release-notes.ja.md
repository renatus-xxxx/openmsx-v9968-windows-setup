# リリースノート案 — 0.5.0

[公開担当者向け手順](publishing.ja.md)

Windows 向け V9968 対応 openMSX セットアップ補助ツールの初回リリースです。C-BIOS と所有 FS-A1GT BIOS の2方式に対応します。

GitHub Releases の Assets から配布 ZIP を取得し、全体を新しいフォルダへ展開し、対応する setup BAT、続いて launch BAT を実行してください。確認・BIOS 結合・開発用の補助ツールは tools にあります。

BIOS とエミュレーター実行ファイルは同梱しません。[セットアップと制限](setup.ja.md)を参照してください。
