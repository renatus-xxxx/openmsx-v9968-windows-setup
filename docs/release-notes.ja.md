# リリースノート — 0.7.5

V9968 TECH DEMOへ **SCENE 7「透明な浅瀬」**を追加しました。**7キー**で直接表示し、**0キー**で全7シーンの自動再生へ戻ります。

- 遠近感のある石床、独立して動くコースティック、屈折、RGB5のSprite mode3による反射を組み合わせます。
- 中央の光の筋は20枚の白い輝き、10枚の淡い光、8本の半透明の反射で表現します。波と照明の近似計算はPythonで事前に行い、MSX側で素材を合成します。
- スプライト属性をOTIRで転送し、検証用の同等なC言語での実装も残しました。
- デモを **8 MiBのASCII16-X ROM**へ拡張し、起動・バンク切り替え・ビルド・検査を対応させました。標準ASCII16では不足します。既存ベンチマークROMは変更していません。
- 固定V9968 openMSX **14215c7**、openMSX 21.0、C-BIOS 0.29は維持します。

固定エミュレーターでのScene 7の実測は **C-BIOS/Z80が9.00fps、FS-A1GT/R800が11.20fps**（5秒ウォームアップ・15秒測定・独立起動3回）。実機の性能値ではありません。両CPUのシーン・画素回帰検査を実施しました。今回の外付け0x88・実機FPGA動作は未確認です。半透明と眩しさは近似で、加算HDRや完全な流体計算ではありません。

[Scene 7の技術説明](../demos/v9968-tech-demo/SHALLOW.ja.md)も参照してください。ZIP全体を新しいフォルダへ展開し、対応するsetup BATを実行してください。既存環境と所有BIOSは別に保持してください。実機BIOSは同梱していません。
