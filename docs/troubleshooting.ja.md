# トラブル対処・削除

[トップ](../README.ja.md)

| 条件 | 対処 |
|---|---|
| 直下の起動 BAT が Not installed / 未セットアップと表示 | 対応するセットアップ BAT を先に実行 |
| curl.exe がない | Windows Update と System32/curl.exe を確認。古い Windows 10 では不足する場合があります |
| curl・ネットワーク・HTTP エラー | HTTPS 接続とプロキシを確認して再実行。証明書検査は無効化しません |
| ZIP のサイズ・SHA-256 不一致 | 対象キャッシュを退避し、固定した配布元のバージョンを確認してから再取得 |
| BIOS 不足・未知のバージョン | 必要な2イメージ、サイズ、ハッシュを確認。名前を変えても内容は変わりません |
| 対応する異なるファームウェアのバージョンが同時に存在 | 使用する一組だけを別フォルダへコピー |
| 既存環境が変更済み | 上書きせず停止します。新しいフォルダへ導入 |
| 機種 XML が読めない | XML は UTF-8 BOM なし。PowerShell は5.1で日本語を読める BOM 付き |
| 日本語パスで通常版が起動しない | tools/verify の BAT を使用。作業ディレクトリと ASCII 相対データパスをセットで指定します |
| 自動確認失敗・タイムアウト | runtime/MODE/logs、画面ドライバー、デスクトップを確認。ゲーム全般の互換性を保証しません |
| DLL 不足 | Windows・VC ランタイムを確認。自動インストールは行いません。クリーン OS VM は未検証 |
| C-BIOS で BASIC/BLOAD が使えない | カートリッジ形式か、所有する対応 FS-A1GT BIOS 環境を使用 |
| Windows のポリシーで実行不可 | 組織の方針に従ってください。AppLocker/WDAC を回避しません |
| 結合先が既にある | 未作成の OutputDir を指定。既存ファイルは上書きしません |


## 削除

openMSX と BAT ウィンドウを閉じるとプロセス内の設定は終了し、元のエミュレーターは従来のショートカットから起動できます。必要なセーブを退避してから、今回作成した runtime・cache・private・build・dist だけをエクスプローラーで削除します。失敗時の staging・lock・part ファイルも、関連プロセス終了後に削除できます。元の BIOS フォルダや別のエミュレーターは削除しないでください。レジストリの復旧や管理者アンインストーラーは不要です。
