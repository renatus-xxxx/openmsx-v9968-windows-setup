# トラブル対処・削除

[トップ](../README.ja.md)

該当する状況を下から探してください。セットアップと起動はログを残し、画面のメッセージにログの場所を表示します。原因が分からない場合はまずログを確認してください。

## セットアップが始まらない

| 条件 | 対処 |
|---|---|
| curl.exe がない | Windows Update と System32/curl.exe を確認。古い Windows 10 では不足する場合があります |
| Windows のポリシーで実行不可 | 組織の方針に従ってください。AppLocker/WDAC を回避しません |

## ダウンロードと検証

| 条件 | 対処 |
|---|---|
| curl・ネットワーク・HTTP エラー | HTTPS 接続とプロキシを確認して再実行。証明書検査は無効化しません |
| ZIP のサイズ・SHA-256 不一致 | 対象キャッシュを退避し、固定した配布元のバージョンを確認してから再取得 |

## FS-A1GT の BIOS

| 条件 | 対処 |
|---|---|
| BIOS 不足・未知のバージョン | 必要な2イメージ、サイズ、ハッシュを確認。名前を変えても内容は変わりません |
| 対応する異なるファームウェアのバージョンが同時に存在 | 使用する一組だけを別フォルダへコピー |
| 結合先が既にある | 未作成の OutputDir を指定。既存ファイルは上書きしません |

## 起動

| 条件 | 対処 |
|---|---|
| 確認用 BAT（tools/verify）が Not installed / 未セットアップと表示 | 対応するセットアップ BAT を先に実行 |
| 既存環境が変更済み | 上書きせず停止します。新しいフォルダへ導入 |
| DLL 不足 | Windows・VC ランタイムを確認。自動インストールは行いません。クリーン OS VM は未検証 |
| 機種 XML が読めない | XML は UTF-8 BOM なし。PowerShell は5.1で日本語を読める BOM 付き |
| 日本語パスで通常版が起動しない | tools/verify の BAT を使用。作業ディレクトリと ASCII 相対データパスをセットで指定します |

## 識別結果と動作

| 条件 | 対処 |
|---|---|
| 確認の失敗・タイムアウト | runtime/MODE/logs、画面ドライバー、デスクトップを確認。ゲーム全般の互換性を保証しません |
| C-BIOS で BASIC/BLOAD が使えない | カートリッジ形式か、所有する対応 FS-A1GT BIOS 環境を使用 |

## 削除

1. openMSX と BAT ウィンドウを閉じます。プロセス内の設定は終了し、元のエミュレーターは従来のショートカットから起動できます。
2. 必要なセーブデータを退避します。
3. 今回作成した runtime・cache・private・build・dist のフォルダだけを、エクスプローラーで削除します。

失敗時の staging・lock・part ファイルも、関連プロセスの終了後に削除できます。元の BIOS フォルダや別のエミュレーターは削除しないでください。レジストリの復旧や管理者アンインストーラーは不要です。

## デモの起動エラー

- `Run setup-... first`：対応するルートの setup BAT を実行してください。
- `Emulator hash mismatch`：エミュレーターが検証済みのものと異なります。別フォルダに全体を展開してセットアップし直してください。
- `Demo ROM is missing` / `Expected a 1 MiB ASCII16-X ROM`：ZIP全体を展開してください。開発者はデモを再ビルドできます。
- `Cached demo ROM hash mismatch` / `Local BIOS copy differs`：既存のデモ用コピーと元データが一致しません。`runtime/<mode>/user-tech-demo/` の該当フォルダをバックアップしてから別名へ変更し、再起動してください。所有BIOSの元ファイルや runtime 全体は削除しないでください。
- パスが長すぎる場合は、短い書き込み可能な場所へZIP全体を展開してください。
