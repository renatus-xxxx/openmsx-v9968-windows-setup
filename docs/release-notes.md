# Release notes — 0.5.0

[Home](../README.md)

Initial release of unofficial Windows setup helpers for the V9968-enabled openMSX fork, using C-BIOS or a user-owned FS-A1GT BIOS.

Download the distribution ZIP from **Assets** on GitHub Releases and extract the whole ZIP into a new folder. Run the matching setup BAT, then the launch BAT. Verification, BIOS joining and development helpers are under tools.

No BIOS or emulator executable is bundled. See [setup and limits](setup.md).
