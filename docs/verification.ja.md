# 検証結果 — 0.5.0

[トップ](../README.ja.md) | [検証結果の詳細（JSON）](../tests/verification.json)

確認日：2026-09-09。Windows 10 x64 build 19045、Windows PowerShell 5.1.19041.7725、curl 8.13.0、z88dk classic/sccz80 を使用しました。

## 今回の確認

- 固定の z88dk 探索候補がなく、明示指定・Z88DK・ZCCCFG・PATH による検出が成功。
- 不正な自動候補を飛ばし、不正な明示指定では停止。
- 未検出時の選択、キャンセル、不正選択を模擬入力で確認。ネイティブダイアログの手操作とは区別しています。
- 独立した日本語・空白パスの ZIP 展開先で C ROM を再ビルド。ROM の SHA-256 は config/versions.json と一致。
- 日英リンク、公開対象一覧、ルートの4 BAT、ZIP 内容を検査。

## 同日に取得した検証結果を利用する項目

以下は今回の z88dk 検出修正後に再実行したものではありません。セットアップ・エミュレーター処理と確認 ROM の変更はありません。

- 両方式のセットアップ・確認・起動で VDP ID=3、通常版比較で ID=2。
- FS-A1GT の BASIC 起動で MSX BASIC 4.1 / Disk BASIC 2.01 / Ok。
- 日本語・空白パス、リポジトリ外の作業ディレクトリ、同一 ROM の重複候補に対応。
- BIOS 結合の一致復元、既存出力の拒否、欠落・不一致での停止。入力は所有イメージのローカル分割データです。
- BIOS 不足・内容不一致、管理記録のない既存出力、キャッシュ改変、接続不能プロキシ、管理対象設定・ROM 改変で停止。再実行時はユーザー設定を保持。

起動試験は一時 Tcl で画面文字を取得して終了しています。試験用 Tcl と所有 BIOS は配布しません。C プログラム実行時の CPU は z80 でした。
