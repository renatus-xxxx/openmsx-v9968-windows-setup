# 変更履歴

## 0.7.0

- テクニカルデモに6つ目のシーン 6 AFTERGLOW を追加。減衰する残像から再帰フレームバッファフィードバックへ移行する演出で、VRAM 間コマンドだけで構成しています。
- その前半に、明るさを色番号の立っているビット数で定義した無彩色パレットを使用し、立体を一色で描画。毎フレーム AND 1回でちょうど1段ずつ均等に減衰します。
- 前半で保持しているページを毎フレーム少しずつ拡大。消えていく複製が立体の下から外へ出るため、上書きされて隠れることがなくなりました。
- 全シーンのヘッダーを、背景画像の帯を貼り直すのではなく、完成した画面へ1ドットのドロップシャドウ付きで描画。タイトル文字の背景画像への焼き込みをやめ、Scene 3 のヘッダー帯も他と同じように水面とともに動くようになりました。
- パレット転送を1フレーム1回、垂直帰線期間に実施。表示期間中に2回書いていたため、走査線の一部が別のパレットで描かれていました。
- 起動時に LRMM を1回実行して転送の有無を調べ、R20 の bit5 を決定。派生版 openMSX と FPGA のレジスタ配置について報告された差異に対応する設計です。FPGA 側の分岐は当方では未検証です。
- 配置先に未対応の再解析ポイント（クラウド同期に伴うことが多いもの）がある場合、リンク・ジャンクションとして報告するのではなく、理由と展開先の案内を示して停止するようにしました。
- 最初の LRMM 判定が失敗して R20 を 0x31 に切り替えた場合は再判定し、0x11 で成功した場合はその結果を保持します。誤判定は Scene 6 のフィードバックを黙って失うのではなく、キャプチャテストの失敗として現れます。この判定は1つのスイッチの内側にまとめてあり、エミュレータ側が FPGA と一致した時点でブロックごと削除できます。
- ヘッダーの検査を、文字が正しい位置に載ることの確認だけでなく、転送元の帯が実在すること、および転送先の絵が透明部分で保たれることの確認まで広げました。あわせて Scene 6 のフィードバックの履歴ページにヘッダーが入り込んでいないことも検査します。
- 公開前検査で、ベンチマークの測定結果が同梱 ROM を指していること、および BAT が呼ぶスクリプトが公開一覧に含まれることを必須にしました。リリース ZIP は作業用の名前で作成し、検査に通ってから最終名にします。
- 識別用カートリッジを適合性確認プローブに拡張しました。起動した機械上で決められた実験を実行し、何が起きたかを表示します。実装間の比較に使う観測値を記録します。ポーリング回数は CPU 間で比較できる実行時間ではなく、実機は未検証です。
- V9968 実装間で食い違いが分かっている箇所を記録するページを追加しました。固定版派生エミュレーターの測定値を記入し、残りは報告待ちとして開いてあります。

## 0.6.1

- デモ ROM の宣言を ASCII16-X から標準 ASCII16 へ変更。バンク切り替えのコードは変更しておらず、同じ ROM は ASCII16-X 対応ハードでもそのまま動作します。
- デモ起動時は同梱 ROM を優先。開発者は `-UseBuild` で自分のビルドを選択します。
- フレーム数をバンク配置情報として生成し、実行時のマスクに使用。フレーム数を変更しても次の資産を読み込みません。
- ASCII16 の 256 バンク上限を超える ROM は生成時に停止し、代替として ASCII16-X を案内します。
- マッパー異常時の画面表示を V9968 未検出時と統一し、デモ起動スクリプトの到達しない分岐を削除。

## 0.6.0

- V9968 TECH DEMO を追加（MSX 8x8 font、5シーン、PSG BGM）。
- V9968 と従来 VDP を比較する SCENE3 BENCHMARK を追加（FULL・FAST・COMPAT の3モードと測定結果）。
- セットアップ・起動・BIOS 結合のメッセージを英日併記化し、VDP 識別の失敗時には実測値も表示。
- ルートを2つのセットアップ BAT と機種別デモ起動 BAT に整理。
- 識別画面の起動 BAT は `tools/verify/` へ移動。
- CPU 切り替え・キーボード処理を独立した実装へ変更。
- 説明書を再構成（README の方式比較、英語版ダンプ手順の構成復元、状況別のトラブル対処）。

## 0.5.0 — 初回リリース

- C-BIOS または所有 FS-A1GT BIOS を使用したセットアップ。
- 固定バージョンのダウンロードとハッシュ検証。
- V9968 の起動・識別、通常版比較、BASIC 起動。
- BIOS 結合と確認 ROM のビルド用ツール。
- 日英のセットアップ・開発手順。
