# 変更履歴

## 0.6.0

- V9968 TECH DEMO を追加（MSX 8x8 font、5シーン、PSG BGM）。
- V9968 と従来 VDP を比較する SCENE3 BENCHMARK を追加（FULL・FAST・COMPAT の3モードと測定結果）。
- セットアップ・起動・BIOS 結合のメッセージを英日併記化し、VDP 識別の失敗時には実測値も表示。
- ルートを2つのセットアップ BAT と機種別デモ起動 BAT に整理。
- 識別画面の起動 BAT は `tools/verify/` へ移動。
- CPU 切り替え・キーボード処理を独立した実装へ変更。
- 説明書を再構成（README の方式比較、英語版ダンプ手順の構成復元、状況別のトラブル対処）。

## 0.5.0 — 初回リリース

- C-BIOS または所有 FS-A1GT BIOS を使用したセットアップ。
- 固定バージョンのダウンロードとハッシュ検証。
- V9968 の起動・識別、通常版比較、BASIC 起動。
- BIOS 結合と確認 ROM のビルド用ツール。
- 日英のセットアップ・開発手順。
