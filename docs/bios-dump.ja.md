# FS-A1GT 実機からセットアップ用 ROM を作る

[トップ](../README.ja.md)

このセットアップで必要なのは次の2ファイルです。名前だけでなくサイズとハッシュで確認します。

| セットアップ用ファイル名 | サイズ | 内容 |
|---|---:|---|
| `fs-a1gt_firmware.rom` | 4,194,304 bytes（4 MiB） | BIOS/BASIC、サブ ROM、ディスク関連、内蔵ソフト等を含む、openMSX の統合ファームウェアイメージ |
| `fs-a1gt_kanjifont.rom` | 262,144 bytes（256 KiB） | JIS 第1・第2水準の漢字フォント |

FS-A1GT の実 ROM チップをそのまま読み出した物理ダンプと、openMSX の4 MiB統合イメージは同一形式とは限りません。ここでは本体を分解せず、実機で動くダンププログラムを利用する方法を説明します。手元の所有機から取得し、ROM 本体は配布しない運用です。

## 1. 用意するもの

- 正常に起動する FS-A1GT と、動作する内蔵フロッピードライブ。
- MSX と Windows 間でファイルを移せる媒体・ドライブ。以下は 720 KiB フォーマットの 2DD フロッピーを使用する例です。USB フロッピードライブは 720 KiB 媒体を読める機種が必要です。
- プログラム用ディスク1枚、保存用の空ディスク8枚程度。内蔵ファームウェア32分割だけで、1枚に5ファイルずつなら7枚必要です。既存データの入ったディスクを初期化しないでください。
- Windows 側に、取り出したファイルを集約する空フォルダ。

SD等の既存ストレージでもファイルを渡せますが、ダンププログラムは保存先を A: としてディスク交換を案内します。ドライブ割当てが変わる構成は未検証なので、この説明では内蔵 FDD を使います。

## 2. ダンププログラムを入手する

[blueMSX 開発元のリソースページ](https://www.vik.cc/bluemsx/resource.html)の **Panasonic dump tools → FS-A1GT** を使います。機種設定・ROMセットのダウンロードではなく、ダンプツールのリンクを選びます。

- [FSA1GT.zip（ダンプツール）](https://www.vik.cc/bluemsx/rel_download/dump/FSA1GT.zip)
- 必要な場合のみ：[KANJIROM.zip（漢字ダンプツール）](https://www.vik.cc/bluemsx/rel_download/dump/KANJIROM.zip)

2026-09-09に取得した内容は次のとおりです。

| ZIP | 内容 |
|---|---|
| FSA1GT.zip | `FSA1GT.BAS`、`FSA1GT.DSK` |
| KANJIROM.zip | `KANJIROM.BAS`、`KANJIROM.DSK` |

この配布資料に第三者のダンプツールは同梱していません。上記配布元から取得してください。通常のファイル転送で `.BAS` をプログラム用ディスクにコピーすれば、この手順を実行できます。`.DSK` はディスク全体のイメージで、ディスクへファイルとしてコピーするだけではその中身を展開できません。ここでは `.DSK` の書込みは不要です。

## 3. 実機を起動する

1. 本体の内蔵ソフト起動を OFF にし、プログラム用ディスクを入れます。
2. **キーボードの「1」を押しながら起動**します。blueMSX のツール配布ページが turboR について指定している起動方法です。Disk BASIC 1 側で作業するため、通常の Disk BASIC 2 起動と混同しないでください。
3. BASIC の `Ok` で次を実行します。

```basic
RUN "FSA1GT.BAS"
```

DOS プロンプトが出るディスクを使っている場合は、`BASIC` で BASIC に戻ってから実行します。以降はダンププログラムのメニューとディスク交換の指示に従います。

## 4. メイン ROM と漢字 ROM を保存する

メニューの **1: Main System ROM BIOS** を選び、指示が出たら空の保存用ディスクに交換してキーを押します。

ソース上、この選択は BIOS、拡張 BIOS、漢字ドライバー、漢字フォント、音楽 BASIC、オープニング、ディスク関連のファイルを保存します。このうち今回使用するのは **`A1GTKFN.ROM`（256 KiB）**です。BASIC ROM の `A1GTBIOS.ROM` だけでは、今回の 4 MiB 統合ファームウェアの代用にはなりません。

完了後、ディスクを取り出して内容を Windows 側へコピーし、保存してください。書込み中に取り出さないでください。

漢字 ROM だけを別に取り出す場合は `RUN "KANJIROM.BAS"` を実行し、**2: JIS 1st/2nd Class Kanji** を選びます。生成される **`KANJI.ROM` は 256 KiB** です。メニュー1では第1水準だけの 128 KiB になるため、今回の用途には不足します。こちらも「1」を押しながら起動する指定があります。

## 5. 内蔵ファームウェアを保存する

FSA1GT.BAS のメニューに戻り、**2: Internal Firmware ROMS** を選びます。空のディスクへの交換指示に従って保存を続けます。

生成物は **`A1GTFIRM.000`～`A1GTFIRM.01F` の32ファイル**です。各ファイルは **131,072 bytes（128 KiB）**で、拡張子は16進数です。

```text
A1GTFIRM.000 ... A1GTFIRM.009
A1GTFIRM.00A ... A1GTFIRM.00F
A1GTFIRM.010 ... A1GTFIRM.019
A1GTFIRM.01A ... A1GTFIRM.01F
```

ディスク交換中にどこまで出力したかを記録し、Windows 側の1つのフォルダへ全32ファイルを集めます。同じフォルダへ、先ほどの `A1GTKFN.ROM` または `KANJI.ROM` もコピーします。

**ツールのソースには、一部のファームウェア領域を FF で埋めて出力する処理があります。** したがって、ここで作るファイルはこのツールとエミュレーター向けの論理イメージで、ROMチップの全ビットを保存した物理アーカイブと同一とは説明しません。受入れ可否は次のハッシュ照合で判断します。

## 6. Windows で結合・検査する

集めたフォルダを **`tools\bios\join-fsa1gt-dump.bat`** へドラッグします。ダブルクリックでは入力フォルダの選択が開きます。既定の出力先は private/fsa1gt-bios です。コマンドプロンプトからは出力先も指定できます。

```bat
tools\bios\join-fsa1gt-dump.bat "D:\FS-A1GT dump" -OutputDir "D:\FS-A1GT ready"
```

出力先には未作成のパスを指定してください。この BAT は32ファイルを番号順に結合し、漢字 ROM とともに検査してから、冒頭の2ファイル名で出力します。元のファイルは変更せず、バイトの書換えや欠落部の補完も行いません。結合後に期待する SHA-1 は以下です。

| ファイル | 許容する SHA-1 |
|---|---|
| fs-a1gt_firmware.rom | `e779c338eb91a7dea3ff75f3fde76b8af22c4a3a` または `5fa3aa79aeba2c0441f349e78e9a16d9d64422ea` |
| fs-a1gt_kanjifont.rom | `5aff2d9b6efc723bc395b0f96f0adfa83cc54a49` |

値は [openMSX 21.0 の FS-A1GT 機種定義](https://github.com/openMSX/openMSX/blob/RELEASE_21_0/share/machines/Panasonic_FS-A1GT.xml)に基づきます。結合スクリプトはハッシュ不一致で出力を中止します。バイトの書換えや、欠落部の自動補完はしません。

一致しない場合は、ファイル欠落、別ディスクの取り違え、転送エラー、ダンプツールのバージョン、本体 ROM のバージョンを確認してください。可能なら別の空ディスクへ再度ダンプし、2回の内容が一致するか比較します。不明なハッシュを許可リストに加えて無理に通す方法は、この手順に含めません。

検査済みのフォルダを `setup-fsa1gt-v9968.bat` へドラッグ＆ドロップすれば、以降は自動セットアップになります。

## 確認した範囲

- 配布元の起動指定と、実際に取得した `.BAS` ソースのメニュー・ファイル名・ブロック数・漢字水準を確認しました。
- 結合スクリプトは、手元の対応 ROM を試験用に32分割したデータから元と同じハッシュを復元できるか検証しています。
- **実機 FS-A1GT を操作してのダンプ作業は今回未実施です。** 結合試験は、実機でのダンプ成功や上記ツールの実機動作を保証するものではありません。
- ツール資料を読む際は [openMSX の ROM 取得ガイド](https://openmsx.org/manual/setup.html#dumprom)も参考になります。一般的な BIOS 保存ツールで作った 32 KiB の ROM を、単に 4 MiB 用の名前へ変更するだけでは使えません。
